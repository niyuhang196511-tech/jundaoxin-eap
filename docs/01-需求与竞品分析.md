## 1. 平台定位

EAP 是一个**企业级智能体操作系统（Agent Operating Platform）**：统一管理模型、知识、智能体、工具、技能、Prompt 六类资产，提供从开发、注册、发布、运行到观测、评测、计费的完整生命周期，并延伸到员工桌面（本地 Harness）与第三方系统（嵌入外链 / A2A）。

它与"普通 AI 应用"的区别在于三面分离：

- **Control Plane**（管什么）：资产注册、配置、治理、计量
- **Runtime Plane**（怎么跑）：执行引擎、上下文工程、任务状态机
- **Data Plane**（真访问）：模型推理、向量/图存储、业务系统、本地桌面

## 4. 结论与借鉴

**没有任何单一产品完整覆盖 EAP 的 8 项差异化需求**：外链嵌入智能体、全面本地 Harness、手写 Agent 注册钩子、定制/专用模型注册这 4 项在开源产品中均为空白或半空白。因此采用 **核心自研 + 集成开源组件** 的混合构建策略。

值得借鉴的成熟模式：

| 来源 | 借鉴点 | 用在哪 |
|---|---|---|
| Coze | 发布为多渠道（网页/API/聊天窗口）、插件市场运营 | 发布与集成层、插件市场 |
| Dify | Model Provider 抽象（供应商/模型/配额分层）、工作流 DSL | 模型中心、Workflow Engine |
| RAGFlow | DeepDoc 深度文档解析（版面/表格/OCR） | 知识中心 Ingestion |
| FastGPT | 知识库问答的产品化拆分（应用↔知识库解耦） | 知识中心多 KB 实例模型 |
| LangGraph | Checkpoint/HITL/状态图运行时 | Agent Runtime 的实现组件（非内核本身） |
| n8n | 节点生态与连接器治理 | 连接器中心 |
| 影刀 | 桌面自动化权限模型、命令市场 | Harness 沙箱与技能市场 |
