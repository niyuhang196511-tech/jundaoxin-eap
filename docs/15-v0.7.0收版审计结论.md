## 一、结论

v0.7 新增代码（统一 Extension Manifest / 持久注册表 / .eapext Bundle 生命周期 /
SDK 契约）**未引入新的高危发现**。继承的 5 个 MinerU 数据流 SSRF 发现维持
docs/12/13 判定（补偿控制就位：sanitize_url 全量校验 + 组件重建 + batch_id
白名单；API 合同本质，可接受）。

## 二、本轮安全相关审查要点

1. **Bundle 安全面**（本轮重点审查）：.eapext zip 安装实施了逐条目校验——
   路径拒绝绝对路径与 `..`、文件名白名单、10MB/100 文件上限、解压目标
   resolve + is_relative_to 锁定 plugins_dir 内、manifest 格式即校验
   （min_version 格式 / type 白名单）。
2. **安装/卸载/启停全部审计**（extension.install/enable/disable/uninstall）。
3. **信任边界不变**：扩展 = 受信代码，进程内执行（与内置 AgentApp 同边界，
   docs/04 §8 既有约定）；admin 权限门禁控制安装与卸载。
