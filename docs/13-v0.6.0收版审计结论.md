## 一、结论

v0.6 新增代码（治理基线修复 / Tool Governance / Policy Engine 扩展 / 评测深化 /
成本计量 / Memory 治理）**未引入新的高危发现**。存量继承的 5 个 MinerU 数据流
SSRF 发现维持 docs/12 的判定（补偿控制就位，API 合同本质，可接受）。

## 二、本轮安全相关改进（治理本身即安全特性）

1. **RBAC 收口**：budgets / releases 全写端点 / plugins-reload 补 require_admin
   （此前发布治理可被任意 API Key 绕过门禁）。
2. **审计补全**：release 生命周期、budgets、connectors、models、skills、prompts、
   workflows、mcp、evals、embed 全部落审计；新增审计查询页（action/actor/target/
   时间过滤 + 分页）。
3. **Tool Governance**：工具风险分级 + 策略白名单 + 风险审批阈值 + 委派边界；
   循环内每次工具调用落审计与指标（此前循环内工具调用无任何治理观测）。
4. **成本计量修复**：SSE 流式对话此前记在 tenant 0（租户预算永不熔断）——已修复。
5. **IM secret 加密**：Fernet 加密（明文兼容期语义保留）。
6. **Memory 治理**：租户归属与过滤、保留期清理、按用户批量遗忘/导出（数据权利）。
