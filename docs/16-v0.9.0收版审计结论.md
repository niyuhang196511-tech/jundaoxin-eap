## 二、本轮安全相关审查要点（逐线）

1. **Webhook 推送（M31）**：签名 `HMAC-SHA256(raw_body, secret)` + `hmac.compare_digest`
   时序安全比较（与 M30 入站对称）；secret Fernet 加密、查询不回显；出站 10s 超时；重试不放大
   （指数退避封顶 + dead 死信）。
2. **IM 深化（M30）**：回调沿用三平台既有签名验证（challenge/加签/SHA1+AES）；应用凭据
   Fernet 加密、响应掩码不回显；重试队列幂等键 channel+event_key 唯一约束兜底并发。
3. **A2A 深化（M30）**：委派 **fail-closed**（新策略 kind `a2a-delegate-allowlist`，默认拒绝、
   策略校验先于任何出站请求——拒绝时零触网）；复用 M24 深度护栏防委派循环；跨租户任务隔离；
   推送回执 HMAC 签名。
4. **连接器深化（M31）**：SQL 连接器只读白名单 **fail-closed**（剥注释 → 首词 SELECT → 写关键字
   词边界全文拒绝防粘词绕过 → 仅末尾单分号；字符串字面量含关键字同样拒绝）；参数绑定防注入；
   OAuth secret/access/refresh 全 Fernet 加密；authorization_code state 防 CSRF/重放；
   行数上限防拖库。
5. **API Gateway（M31）**：并发/请求体/超时/幂等四层防护；幂等存储仅缓存响应体（无凭证落盘）；
   SSE 流式路径显式排除（chat/A2A 前缀 + Accept 头判断）；中间件顺序经审查固定
   （RequestSize → Concurrency → Idempotency）。
6. **工具沙箱（M33）**：子进程 env 白名单裁剪（仅 PATH/TEMP 等 + 协议变量）；超时树杀；
   **隔离级别诚实声明——软隔离（cwd 约定 + env 裁剪），非容器级**：绝对路径越界写入无技术
   阻断，已写入模块 docstring 与账本剩余工作（升级路径：容器/bwrap）；`tool-sandbox` 策略
   enforce 模式 fail-closed。
7. **Worker 池（M32）**：租约恢复用抢占式 UPDATE 防多副本重复入队；幂等键已知非原子窗口
   （无部分唯一索引，at-least-once 语义，docstring 与账本已记录）。
8. **CI/CD（M32/M33）**：workflow `permissions` 最小化并注释；`workflow_dispatch` inputs
   白名单校验防注入（environment 枚举 + image_tag 字符集）；修复 ci.yml 自 M13.1 起的
   YAML 解析错误（未引号冒号致 Actions 拒载——属可用性而非安全，但意味此前 CI 保护长期未生效，
   本轮恢复）；check_docs 文档一致性门禁入 CI。
